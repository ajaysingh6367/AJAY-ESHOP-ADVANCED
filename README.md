# Ajay E-Shop — Advanced React Project

A responsive e-commerce frontend built with React and Vite. It includes product browsing, search, category and rating filters, sorting, quick-view product details, wishlist, cart quantity controls, demo checkout, order history, and demo sign-in.

## Run locally

1. Install Node.js (LTS) from https://nodejs.org if you don't have it.
2. Open this folder in VS Code.
3. Choose **Terminal → New Terminal**.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the localhost URL printed by Vite (usually http://localhost:5173).

## Features

- Product cards with real product photography from Unsplash
- Search, category filters, rating filters, and price/rating sorting
- Quick view modal with product details
- Add to cart, update quantities, and remove items
- Cart and wishlist saved in browser localStorage
- Demo sign-in and demo order checkout (no real payments)
- Order history saved in browser localStorage
- Responsive mobile and desktop layout

## Notes

This is a frontend demo project. Sign-in is not connected to a server, and checkout does not charge money or create a real shipment. Product photos load from Unsplash and need an internet connection.
